## What is this?

A collection of service-site codebases for home appliance repair brands. Each sub-site is independently deployable and covers a specific brand or service focus.

## 🏠 Sites

| Folder | Brand | Focus |
|---|---|---|
| `homesure/` | HomeSure | General home appliance repair |
| `surefix/` | SureFix | AC, dishwasher, dryer repair |
| `demo/` | Demo / staging | Development previews |

## 🗂️ Each Site Has

- Service landing pages per appliance type (AC, dishwasher, dryer, washing machine)
- Blog / tips section
- Contact and booking form
- SEO-optimised `sitemap.php` and `robots.txt`
- Admin panel

## 🚀 Deploy

1. Copy a site folder to your web host
2. Configure DB credentials
3. Import schema from `docs/`
